# Lunaor — Web Applications Studio Website

Modern, colorful, Noosa Beach pastel landing page and central mothership hub for **Lunaor**, an independent software development studio based in Noosa Heads, Queensland, Australia.

## ✨ Features & Design Highlights

- **🏖️ Noosa Beach Pastel Aesthetic**: Sun-drenched pastel palette (coral, peach, ocean sky aqua, eucalyptus sage, and buttery sunshine) with soft drifting radial gradient meshes and glassmorphism.
- **🚀 The Independent Studio Model**: Highlighting Lunaor's philosophy of designing, engineering, and operating proprietary web applications for ourselves across their own dedicated domains.
- **🕒 Live Noosa Local Clock**: Real-time Queensland local time (`AEST / UTC+10`) and coastal vibe badge.
- **🎨 Interactive Sandbar Playground**: Interactive canvas allowing visitors to drop pastel coastal/software stickers onto the Noosa canvas with delightful confetti physics.
- **❤️ Signature Footer**: **"Made in Noosa with ❤️"** with glowing animated badge and quick studio contact modal.

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom Pastel Color Gradients + Glassmorphism
- **Icons**: Lucide React
- **Package Manager / Runtime**: Bun

## 🚀 Getting Started

### Development
```bash
# Start local development server on http://localhost:3000
bun run dev
```

### Production Build
```bash
# Build optimized production bundle to /dist
bun run build

# Preview production build locally
bun run preview
```
